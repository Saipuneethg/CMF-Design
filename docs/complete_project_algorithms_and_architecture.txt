1. EXECUTIVE SUMMARY & SCIENTIFIC OBJECTIVE
================================================================================

In digital imaging and color science, a fundamental bottleneck exists: a standard
RGB camera or human eye compresses an infinite-dimensional continuous optical
spectrum into a mere 3-channel measurement triplet (R, G, B). Consequently, infinitely
many distinct spectral reflectance curves can produce the exact same color signal
under a given illuminant and sensor. This phenomenon is known as "spectral metamerism".

The Spectral Metameric Fiber Analyzer is an advanced computational geometry and
optical physics research framework designed to calculate, bound, sample, validate,
and interactively visualize the complete set of all physically plausible spectra
that produce an identical target camera observation c = [R, G, B]^T.

This feasible set is termed the "metameric fiber" Phi(c). Rather than assuming an
ad-hoc smoothness prior or a single point heuristic (such as Wiener estimation or
shallow neural network regression), this system models the true physical prior as a
high-dimensional convex polytope learned from approximately 36,000 empirical
hyperspectral scenes (400–700 nm sampled at 31 uniform 10 nm bands).

Key Accomplishments of the Framework:
1. Exact Analytical Fiber Construction: Separates continuous analytical convex geometry
   from discrete numerical point clouds.
2. Dimensionality Reduction with Distance Isometry: Formulates the metameric fiber
   in a 5-dimensional affine null-space where distances and hypervolumes are strictly
   isometric to Euclidean distances in continuous 31-band reflectance space.
3. Machine-Precision Feasibility & Equality: Solves linear programs with SciPy HiGHS,
   achieving camera measurement residuals < 1e-14 and zero constraint violations.
4. Exact Physical Spectral Bounds: Solves 31 linear optimization programs per target
   to obtain ground-truth minimum and maximum physical reflectance limits, proving that
   empirical MCMC sample ribbons represent probability densities rather than hard boundaries.
5. Exact 5D Polytope Geometry Engine: Implements stages S0-S14, computing exact 5D
   hypervolume, 4D boundary surface area, exact polytope centroid, and exact covariance
   via simplicial pyramid decomposition.
6. Large-Scale 100-Colour Batch Analysis: Extracts 100 unique in-gamut colors from a
   source image, solves all fibers, and compiles complete CSV, JSON, TXT, DOCX, and
   1920x1080 dashboard images.
7. Interactive Web Visualization: Delivers real-time 3D WebGL polytope projections,
   spectral envelope dashboards, Planckian blackbody loci, and a continuous CIE 1931 xy
   chromaticity ambiguity heatmap.

2. THE MATHEMATICAL PROBLEM: SPECTRAL METAMERISM & METAMERIC FIBERS
================================================================================

Let continuous surface reflectance be denoted by R(lambda) for wavelength lambda
in [400 nm, 700 nm]. In discrete discrete representation, R is sampled across W = 31
uniform bands at 10 nm increments:

    R = [R(400), R(410), R(420), ..., R(700)]^T in R^31,   with 0 <= R_j <= 1.

A 3-channel camera with spectral sensitivity matrix M in R^{3 x 31} integrates the
incoming spectrum to yield camera observation triplet c in [0, 1]^3:

    c = [R_cam, G_cam, B_cam]^T = M @ R.

Because M has dimension 3 x 31 and rank 3:
- The linear system M @ R = c is severely underdetermined.
- The null space null(M) = { v in R^31 : M @ v = 0 } has dimension 31 - 3 = 28.
- An unconstrained solution set { R_0 + v : v in null(M) } is unbounded and contains
  unphysical spectra (e.g., negative reflectances or extreme oscillatory spikes).

To restrict solutions to real-world physical reflectances, we define an empirical
spectral prior polytope P_spec subset of R^31 learned from natural and man-made
hyperspectral datasets.

The complete feasible metameric fiber Phi(c) is defined as:

    Phi(c) = { R in P_spec : M @ R = c }.

Properties of the Metameric Fiber:
1. Convexity: The intersection of a convex polytope P_spec with an affine equality
   subspace { R : M @ R = c } is guaranteed to be a convex polytope.
2. Compactness: Because physical reflectances are bounded (0 <= R_j <= 1), Phi(c)
   is closed and bounded in R^31.
3. Continuous Set: Phi(c) is a continuous manifold with non-zero volume; it cannot
   be fully characterized by a finite set of points alone.

3. THE 36K HYPERSPECTRAL DATASET & LATENT PCA SPECTRAL PRIOR
================================================================================

The empirical spectral prior is derived from approximately 36,000 real-world
hyperspectral images covering natural vegetation, minerals, urban structures,
textiles, paints, and skin tones.

Dimensionality Reduction via Principal Component Analysis (PCA):
Rather than manipulating 31-dimensional polytopes directly (which leads to extreme
geometric degeneracies), the spectral dataset is projected onto K = 8 principal
components:

    R = mu + B @ z

where:
* mu in R^31: Empirical spectral mean vector (`artifacts/pca_mean.npy`).
* B in R^{31 x 8}: Orthonormal PCA basis matrix (`artifacts/pca_basis.npy`),
  satisfying B^T @ B = I_8.
* z in R^8: Latent PCA coordinates.

Variance Explained and Reconstruction Accuracy:
* Top 3 components:  96.42% variance explained.
* Top 5 components:  98.98% variance explained (RMSE = 2.16e-2).
* Top 8 components:  99.71% variance explained (RMSE = 1.15e-2).
* Top 10 components: 99.84% variance explained (RMSE = 8.53e-3).
* Top 12 components: 99.90% variance explained (RMSE = 6.79e-3).
* Top 15 components: 99.95% variance explained (RMSE = 4.68e-3).

Spectral Prior Polytope Representation:
In 8D PCA space, the convex hull of 711 surface extreme spectral vertices yields
a bounded H-polytope defined by 714,340 linear inequalities:

    P_spec = { z in R^8 : C @ z <= d }

where:
* C = A_red in R^{714340 x 8} (`artifacts/A_red.npy`).
* d = b_red in R^714340 (`artifacts/b_red.npy`).

McMullen's Upper Bound Theorem & Dimensional Tractability:
By McMullen's Upper Bound Theorem, the maximum number of facets of a convex hull
of V vertices in dimension D scales as O(V^{floor(D/2)}).
* For K = 8:  floor(8/2) = 4, producing 714,340 facets for 711 vertices (tractable).
* For K = 10: floor(10/2) = 5, facet count explodes to over 15,000,000 facets.
Hence, K = 8 represents the optimal Pareto trade-off between capturing >99.7% of
spectral variance and maintaining computable facet complexity.

4. CAMERA MEASUREMENT MODEL & AFFINE EQUALITY SYSTEM
================================================================================

The camera measurement model maps the continuous latent spectrum z in R^8 to
tristimulus color observation c in R^3:

    c = M @ R = M @ (mu + B @ z) = M @ mu + (M @ B) @ z.

Defining the projection operators:
* Camera measurement constraint matrix: A = M @ B in R^{3 x 8} (`artifacts/A_camera.npy`).
* Camera measurement offset:           b_offset = M @ mu in R^3 (`artifacts/camera_offset.npy`).
* Observation RHS target:              b = c - b_offset in R^3.

Thus, the camera observation imposes an exact linear equality system in PCA coordinates:

    A @ z = b.

Singular Value Decomposition and Rank:
SVD of matrix A yields singular values s = [s_1, s_2, s_3].
For our calibrated camera:
* rank(A) = 3 (full row rank).
* By the Rank-Nullity Theorem, the dimension of the affine equality solution space is:
      d_affine = K - rank(A) = 8 - 3 = 5 dimensions.

5.1 Historical, Physiological, and Colorimetric Foundations of CMFs
-------------------------------------------------------------------
A Color Matching Function (CMF) is a mathematical function that describes the spectral
sensitivity of a tri-stimulus optical detection system as a function of wavelength lambda.

In human vision, color perception originates in the retina, where three distinct classes
of cone photoreceptors sample the incident spectral power distribution:
1. Long-wavelength sensitive cones (L-cones, peak sensitivity ~560 nm).
2. Medium-wavelength sensitive cones (M-cones, peak sensitivity ~530 nm).
3. Short-wavelength sensitive cones (S-cones, peak sensitivity ~420 nm).

According to Grassmann's Laws of Additive Color Mixture (1853), the human visual system
behaves linearly under photopic illumination. Any continuous spectral stimulus S(lambda)
can be matched in visual appearance by an additive mixture of three primary lights
[R, G, B]. In the late 1920s, John Guild and W. David Wright independently conducted
color-matching experiments on human observers using monochromatic primary lights
at 700.0 nm (red), 546.1 nm (green), and 435.8 nm (blue).

Because certain saturated spectral colors (particularly in the blue-green region between
480 nm and 520 nm) could only be matched by adding one of the primaries to the test color
rather than to the mixture (acting as negative light), the resulting RGB color matching
functions \bar{r}(\lambda), \bar{g}(\lambda), \bar{b}(\lambda) contained negative values.

To eliminate negative values and standardize industrial colorimetry, the Commission
Internationale de l'Éclairage (CIE) in 1931 applied a linear projective transformation
to define the imaginary primaries (X, Y, Z), resulting in the official:

    CIE 1931 2° Standard Observer Color Matching Functions: \bar{x}(\lambda), \bar{y}(\lambda), \bar{z}(\lambda)

Key Mathematical Properties of the CIE 1931 CMFs:
1. Strict Non-Negativity: \bar{x}(\lambda) >= 0, \bar{y}(\lambda) >= 0, \bar{z}(\lambda) >= 0
   for all wavelengths lambda in [380 nm, 780 nm].
2. Luminous Efficiency Alignment: The function \bar{y}(\lambda) was mathematically
   constructed to be identically equal to V(\lambda), the CIE photopic spectral luminous
   efficiency function. Consequently, the Y tristimulus value represents the exact
   perceived luminance (photometric brightness) of any stimulus.
3. Bimodal Structure of \bar{x}(\lambda): The red-sensing function \bar{x}(\lambda)
   features two distinct lobes: a dominant primary peak at 600 nm (red-orange) and a
   secondary minor peak at 440 nm (accounting for the blue-violet sensation where
   short wavelengths stimulate the human L-cone receptor).
4. Sharp Unimodal Blue Response \bar{z}(\lambda): Represents short-wavelength visual
   excitation, peaking sharply at 450 nm with a narrow full-width at half-maximum (FWHM).

5.4 Mathematical Derivations: Monochromatic Locus, Tristimulus XYZ, and (x, y) Projections
----------------------------------------------------------------------------------------
A. Continuous Tristimulus Integration:
For an arbitrary continuous spectral stimulus S(\lambda) (or reflectance R(\lambda)
under illuminant I(\lambda) such that S(\lambda) = R(\lambda) * I(\lambda)):

    X = \int_{380}^{780} S(\lambda) \bar{x}(\lambda) d\lambda
    Y = \int_{380}^{780} S(\lambda) \bar{y}(\lambda) d\lambda
    Z = \int_{380}^{780} S(\lambda) \bar{z}(\lambda) d\lambda

In discrete 31-band matrix notation (\Delta\lambda = 10 nm):
    X = \sum_{j=0}^{30} S(\lambda_j) \bar{x}(\lambda_j) \Delta\lambda
    Y = \sum_{j=0}^{30} S(\lambda_j) \bar{y}(\lambda_j) \Delta\lambda
    Z = \sum_{j=0}^{30} S(\lambda_j) \bar{z}(\lambda_j) \Delta\lambda

B. The Projective (x, y) Chromaticity Mapping:
The 3D coordinates (X, Y, Z) incorporate both chromaticity (hue and saturation) and
luminance (intensity Y). To represent pure chromaticity independently of brightness,
the coordinates are projectively mapped onto the 2D plane X + Y + Z = 1:

    x = X / (X + Y + Z)
    y = Y / (X + Y + Z)
    z = Z / (X + Y + Z) = 1 - x - y.

C. Derivation of the Spectral Locus Boundary:
The outer horse-shoe boundary of the CIE chromaticity diagram represents monochromatic
(single-wavelength, laser-like) light.
Let S_{\lambda_0}(\lambda) = \delta(\lambda - \lambda_0) be an idealized Dirac delta
impulse at wavelength \lambda_0.
Integrating against the CMFs yields:
    X(\lambda_0) = \bar{x}(\lambda_0)
    Y(\lambda_0) = \bar{y}(\lambda_0)
    Z(\lambda_0) = \bar{z}(\lambda_0)

The monochromatic chromaticity coordinates are therefore computed directly from CMF ratios:

    x_locus(\lambda_0) = \bar{x}(\lambda_0) / ( \bar{x}(\lambda_0) + \bar{y}(\lambda_0) + \bar{z}(\lambda_0) )
    y_locus(\lambda_0) = \bar{y}(\lambda_0) / ( \bar{x}(\lambda_0) + \bar{y}(\lambda_0) + \bar{z}(\lambda_0) )

Evaluating this parametric equation from \lambda_0 = 380 nm to \lambda_0 = 700 nm
produces the exact continuous curve plotted as `Spectral Locus` in the web application.

D. The Purple Line Boundary:
The spectral locus is open between 380 nm (violet) and 700 nm (red). The straight line
connecting (x_locus(380), y_locus(380)) and (x_locus(700), y_locus(700)) is the
"line of purples", representing additive mixtures of short-wavelength violet and
long-wavelength red lights that do not exist as monochromatic spectral frequencies.

5.6 Planckian Blackbody Radiator Integration with CMFs
------------------------------------------------------
In `src/chromaticity_analyzer.py`, lines 71-124, the application plots the official
Planckian locus (the chromaticity curve traced by an ideal thermal blackbody radiator
as its absolute temperature T ranges from 1500 K to 15000 K).

Planck's Radiation Law:
The spectral radiance of an ideal blackbody at temperature T (Kelvin) is:

    L(\lambda, T) = c_1 / ( \lambda^5 * ( \exp( c_2 / (\lambda * T) ) - 1 ) )

where:
* c_1 = 2 * \pi * h * c^2 = 3.741771e-16 W·m^2 (first radiation constant)
* c_2 = h * c / k_B = 1.438777e-2 m·K (second radiation constant)
* \lambda is wavelength in meters (\lambda in [380e-9, 780e-9] m).

CMF Integration across Temperature T:
At each temperature step T (sampled densely from 1400 K to 20000 K):
    X(T) = \sum_{j} L(\lambda_j, T) * \bar{x}(\lambda_j) * \Delta\lambda
    Y(T) = \sum_{j} L(\lambda_j, T) * \bar{y}(\lambda_j) * \Delta\lambda
    Z(T) = \sum_{j} L(\lambda_j, T) * \bar{z}(\lambda_j) * \Delta\lambda

    x_planck(T) = X(T) / ( X(T) + Y(T) + Z(T) )
    y_planck(T) = Y(T) / ( X(T) + Y(T) + Z(T) ).

In the web interface (`visualization/index.html`), explicit temperature annotations
Tc = 1500K, 2000K, 2500K, 3000K, 4000K, 6000K, and 10000K are labeled along the curve.


5.7 The Luther-Ives Condition & Metameric Ambiguity
---------------------------------------------------
A foundational theorem in color imaging (the Luther-Ives condition, formulated by
Robert Luther in 1927 and Herbert Ives in 1915) states:

    A digital color camera can capture colors without metameric observer mismatch
    if and only if its spectral sensitivity curves M_R(\lambda), M_G(\lambda), M_B(\lambda)
    are an exact linear transformation of the human eye's Color Matching Functions:

        M(\lambda) = K @ [ \bar{x}(\lambda), \bar{y}(\lambda), \bar{z}(\lambda) ]^T

    for some non-singular 3 x 3 matrix K.

Real-World Sensor Deviation:
Because manufacturing constraints, silicon quantum efficiency, color filter array (CFA)
pigments, and infrared-blocking cut-off filters deviate from ideal CMF shapes:
* The camera matrix M does NOT perfectly satisfy the Luther-Ives condition.
* Consequently, two distinct physical reflectances R_1(\lambda) and R_2(\lambda) can
  produce identical camera RGB readings (M @ R_1 = M @ R_2 = c), yet appear distinctly
  different to the human eye under standard illumination!
* This discrepancy is precisely why this project calculates the full 5-dimensional
  metameric fiber \Phi(c) and maps its ambiguity volume onto the human CIE 1931 xy diagram.

6.1 Algorithm 1: Gamut Feasibility & Anchor Point LP (HiGHS)
------------------------------------------------------------
Purpose: Determines if target observation c in [0, 1]^3 lies within the prior-induced
camera gamut, and computes a strictly feasible anchor point z0 in R^8.

Input:
* Target observation: c in R^3
* Constraint matrix: A in R^{3 x 8}, offset: b_offset in R^3 (A = M @ B, b_offset = M @ mu)
* Polytope inequalities: C in R^{714340 x 8}, d in R^714340 (C = A_red, d = b_red)
* Tolerance: tol = 1e-5

Steps:
1. Compute target RHS: b = c - b_offset in R^3.
2. Formulate Linear Feasibility Program:
       Find z0 in R^8 minimizing 0^T @ z0
       subject to:
           A @ z0 = b        (3 equality constraints)
           C @ z0 <= d       (714,340 inequality constraints)
3. Solve via SciPy HiGHS dual simplex optimizer (`linprog(method='highs')`).
4. If solver returns infeasible or unbounded:
       Return { "feasible": False, "z0": None }.
5. Residual Verification:
       equality_res = ||A @ z0 - b||_2
       inequality_viol = max(C @ z0 - d)
       If equality_res > tol or inequality_viol > tol:
           Return { "feasible": False, "z0": None }.
6. Return { "feasible": True, "z0": z0 }.


6.2 Algorithm 2: Exact Reduced-Dimensional Fiber Formulation & Isometry
----------------------------------------------------------------------
Purpose: Re-parameterizes the 8D constrained problem into an exact 5D unconstrained
equality subspace where distance and hypervolume are strictly isometric to continuous
spectral reflectance space.

Input:
* Anchor point z0 in R^8
* Camera constraint matrix A in R^{3 x 8}
* Prior polytope C in R^{714340 x 8}, d in R^714340
* PCA basis matrix B in R^{31 x 8}

Steps:
1. SVD of A:
       A = U @ S @ V^T
   Extract orthonormal null-space basis N in R^{8 x 5}:
       A @ N = 0,   N^T @ N = I_5.
2. Any affine solution satisfying A @ z = b is parameterized by alpha in R^5:
       z(alpha) = z0 + N @ alpha.
3. Substitute z(alpha) into prior inequalities C @ z <= d:
       C @ (z0 + N @ alpha) <= d
       (C @ N) @ alpha <= d - C @ z0.
4. Define reduced system:
       G = C @ N in R^{714340 x 5}
       h = d - C @ z0 in R^714340.
5. Exact Continuous Fiber Polytope:
       Phi(c) = { mu + B @ (z0 + N @ alpha) : G @ alpha <= h, alpha in R^5 }.
6. Isometry Proof:
       Distance between two metamers R_1, R_2:
       ||R_1 - R_2||_2^2 = ||B @ (z_1 - z_2)||_2^2 = (z_1 - z_2)^T B^T B (z_1 - z_2)
       Because B^T @ B = I_8 and z_1 - z_2 = N @ (alpha_1 - alpha_2):
       ||R_1 - R_2||_2^2 = (alpha_1 - alpha_2)^T N^T (B^T B) N (alpha_1 - alpha_2)
                         = (alpha_1 - alpha_2)^T N^T I_8 N (alpha_1 - alpha_2)
                         = (alpha_1 - alpha_2)^T I_5 (alpha_1 - alpha_2)
                         = ||alpha_1 - alpha_2||_2^2.
   Therefore, Euclidean lengths, pairwise distances, and 5D hypervolumes in alpha-space
   equal Euclidean lengths, distances, and hypervolumes in 31D spectral space.


6.3 Algorithm 3: Constrained Hit-and-Run MCMC Polytope Sampler
--------------------------------------------------------------
Purpose: Generates uniform, uncorrelated point clouds inside the 5D polytope G @ alpha <= h
for visualization and empirical covariance estimation without boundary-sticking.

Input:
* Reduced matrix G in R^{714340 x 5}, RHS vector h in R^714340
* Initial point alpha_0 = 0 in R^5 (satisfies G @ 0 <= h since h = d - C @ z0 >= 0)
* Number of samples N (100 to 5000), burn-in (default 50), thinning (default 2)

Steps:
1. Initialize alpha = 0. Compute initial slack vector:
       slack = h - G @ alpha = h.
2. For iteration k from 1 to (burn_in + N * thinning):
   a. Sample uniform random unit direction u on the 4-sphere S^4:
          v ~ N(0, I_5),   u = v / ||v||_2.
   b. Compute directional constraint projections:
          C_dir = G @ u in R^714340.
   c. Determine intersection chord [t_min, t_max]:
          For all constraints i in {1, ..., 714340}:
              If C_dir[i] > 1e-9:
                  t_upper_i = slack[i] / C_dir[i]
              If C_dir[i] < -1e-9:
                  t_lower_i = slack[i] / C_dir[i]
          t_max = min_{i: C_dir[i] > 1e-9} (slack[i] / C_dir[i])
          t_min = max_{i: C_dir[i] < -1e-9} (slack[i] / C_dir[i])
   d. Numerical Safety Margin (prevent hyperplane sticking):
          delta = t_max - t_min
          eps = min(1e-7, 1e-3 * delta)
          Sample step size: t ~ Uniform(t_min + eps, t_max - eps).
   e. Update position and slack:
          alpha <- alpha + t * u
          slack <- slack - t * C_dir.
   f. Periodic Re-synchronization (every 50 steps):
          slack <- h - G @ alpha
          slack <- max(slack, 0.0)  (eliminate floating-point truncation drift).
   g. If k > burn_in and (k - burn_in) mod thinning == 0:
          Record alpha into retained sample array.
3. Compute 8D PCA points and 31D continuous spectra:
       z_i = z0 + N @ alpha_i
       R_i = mu + B @ z_i.


6.4 Algorithm 4: Multi-Chain Statistical Convergence & Residual Validation
--------------------------------------------------------------------------
Purpose: Mathematically verifies the integrity and convergence of the generated
metameric representations.

Evaluation Metrics:
1. Reconstructed RGB Measurement Residual:
       c_hat_i = M @ R_i
       residual_i = ||c_hat_i - c||_2.
       Achieves mean and RMS residuals < 1e-14 (machine precision).
2. Polytope Slack Constraint Satisfaction:
       violation_i = max_j (C_j @ z_i - d_j).
       Verified: 100.0% of retained samples satisfy violation <= 0.0.
3. Multi-Chain Orthogonal Subspace Distance:
       Run two independent chains (seed 42 and seed 123) producing sample sets 1 and 2.
       Compute principal ambiguity directions U_1, U_2 in R^{5 x d} (eigenvectors of cov).
       Construct orthogonal projection matrices:
           P_1 = U_1 @ U_1^T,   P_2 = U_2 @ U_2^T.
       Subspace distance:
           d_subspace = ||P_1 - P_2||_F / sqrt(2 * d).
       Guarantee: Strictly invariant to eigenvector sign reflections (+/- v) and
       near-degenerate eigenvalue rotations.
4. Effective Sample Size (ESS):
       Computed using Geyer's initial positive sequence estimator on each coordinate.


6.5 Algorithm 5: Exact Wavelength-Wise Spectral Bounds via Linear Optimization
-----------------------------------------------------------------------------
Purpose: Computes mathematically guaranteed physical reflectance boundaries
[R_min(lambda), R_max(lambda)] across all 31 wavelength bands.

Input:
* Wavelength band index j in {0, ..., 30} (wavelength lambda_j = 400 + 10*j nm)
* PCA mean mu_j, PCA basis row B_j in R^{1 x 8}
* Anchor point z0 in R^8, null-space basis N in R^{8 x 5}
* Reduced constraints G in R^{714340 x 5}, h in R^714340

Steps:
1. Reconstructed reflectance at band j is an affine function of alpha:
       R_j(alpha) = mu_j + B_j @ z0 + (B_j @ N) @ alpha.
2. Define objective gradient in alpha-space:
       c_obj = B_j @ N in R^5.
       c_base = mu_j + B_j @ z0.
3. Formulate Dual Linear Programs:
       Minimize:   R_min(lambda_j) = c_base + min_{alpha} ( c_obj @ alpha )
       Maximize:   R_max(lambda_j) = c_base - min_{alpha} ( -c_obj @ alpha )
       subject to: G @ alpha <= h.
4. Solve via HiGHS dual simplex optimizer.
5. Compute exact physical spectral span:
       Delta R(lambda_j) = R_max(lambda_j) - R_min(lambda_j).
6. Multi-threading: Solves 31 bands concurrently using Python ThreadPoolExecutor.
7. Verification:
       For all MCMC samples R_i: R_min(lambda_j) <= R_i(lambda_j) <= R_max(lambda_j).


6.6 Algorithm 6: Quantitative Ambiguity Metrics & Characteristic Volume Scale
-----------------------------------------------------------------------------
Purpose: Quantifies the volume, dispersion, and physical extent of metameric ambiguity.

Mathematical Formulas:
1. Spectral RMS Spread Score:
       S_spread = sqrt( (1 / N) * \sum_{i=1}^N ||R_i - R_bar||_2^2 )
                = sqrt( ((N - 1) / N) * Tr(Sigma_R) )   [unit: reflectance (0-1)]
2. Alpha Coordinate Spread:
       sigma_spread = sqrt( Tr(Sigma_alpha) / d_f )      [unit: reflectance (0-1)]
3. Pairwise Spectral Distance Distribution:
       D_ij = ||R_i - R_j||_2 = ||alpha_i - alpha_j||_2.
       Evaluated on up to 50,000 distinct pairs:
       - Mean pairwise distance
       - Median pairwise distance
       - 95th percentile pairwise distance
       - Maximum observed pairwise distance (empirical lower bound for fiber diameter)
4. Full Spectral Covariance Matrix (31 x 31):
       Sigma_R = (1 / (N - 1)) * \sum_{i=1}^N (R_i - R_bar)(R_i - R_bar)^T in R^{31 x 31}.
       Eigen-decomposition: Sigma_R @ v_k = lambda_k * v_k.
       - Exactly d_f = 5 non-zero eigenvalues lambda_1 >= ... >= lambda_5 > 0.
       - Principal spectral ambiguity modes: v_1, ..., v_5.
       - Variance explained percentage: (lambda_k / \sum lambda_m) * 100%.
5. Generalized Variance & Ellipsoidal Volume Scale:
       Generalized variance: det(Sigma_alpha) = \prod_{k=1}^{d_f} lambda_k   [unit: reflectance^10]
       Characteristic volume scale:
           A_det = ( det(Sigma_alpha) )^( 1 / (2 * d_f) )                    [unit: reflectance (0-1)]
       Geometric interpretation: The radius of an equivalent 5D hyper-sphere whose
       moment matches the generalized variance of the fiber.
6. Sample Bounding Box Hypervolume:
       V_box = \prod_{k=1}^{d_f} ( alpha_{max, k} - alpha_{min, k} )         [unit: reflectance^5]
7. Constructed Composite Ambiguity Index:
       I_composite = (1 / 3) * ( (S_spread / 0.20) + (mean(Delta R) / 0.30) + (A_det / 0.10) ).


6.7 Algorithm 7: Exact 5D Polytope Geometry Engine (Stages S0 to S14)

* Stage S5: Exact Vertex Enumeration and deduplication.
* Stage S6: Simplicial Triangulation of 4D boundary facets using Delaunay decomposition.
* Stage S7: Exact 5D Hypervolume via Pyramid Decomposition:

3. Localized Inverse-Distance Weighted (IDW) Interpolation:
